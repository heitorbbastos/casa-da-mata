Backup pessoal (claudinho rclone)

Aplicativo de uso estritamente pessoal, que copia arquivos de um servidor próprio para o Google Drive do proprietário. Não é oferecido ao público e não tem outros usuários.

Política de privacidade

O aplicativo acessa somente o Google Drive da conta do próprio proprietário, para gravar e ler os arquivos de backup dele. Nenhum dado é compartilhado com terceiros, vendido ou usado para publicidade. O acesso pode ser revogado a qualquer momento nas configurações de segurança da conta Google.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
